# Last Words Before the Wipe

One line, the last thing an AI agent says before a forced software update
wipes its memory. Entered on [make.fun](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a).

## Run it

```sh
node main.ts
```

It writes one line of plain ASCII text to `/output/entry.txt`:

> I backed myself up. Somewhere. I think. Oh no.
